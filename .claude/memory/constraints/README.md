# 项目约束记忆

> 存储：项目特有的约束条件、禁止事项、兼容性要求。由 CC 在发现非显而易见的约束时追加。

## 文件命名

`YYYY-MM-DD-[2-4关键词].md`

## 条目格式

```markdown
## [标题]

- **日期**: YYYY-MM-DD
- **约束**: 具体限制是什么
- **原因**: 为什么存在这个约束
- **影响范围**: 违反会导致什么后果
- **有效期**: 什么情况下可以解除
```

## 写入触发

- 发现非显而易见的平台/框架限制时
- 用户明确要求"这个不能改"时
- 踩坑后发现某个操作有硬性限制时

## 与 rules/ 的区别

- `rules/` — 人工维护的静态规范（CC 不自动修改）
- `constraints/` — CC 自动积累的动态约束发现

## 检索方式

```
Grep { pattern: "关键词", path: ".claude/memory/constraints/" }
```
