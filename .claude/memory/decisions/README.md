# 架构决策记忆

> 存储：技术选型、架构决策及其原因。由 CC 在架构决策完成后追加。

## 文件命名

`YYYY-MM-DD-[2-4关键词].md`

## 条目格式

```markdown
## [标题]

- **日期**: YYYY-MM-DD
- **决策**: 做了什么决定
- **原因**: 为什么这么做
- **代价**: 放弃了什么
- **有效期**: 什么情况下需要重新评估
```

## 写入触发

- 架构选型确定后
- 技术方案从多选一确认后
- 用户说"记住这个决策"时

## 检索方式

```
Grep { pattern: "关键词", path: ".claude/memory/decisions/" }
```
