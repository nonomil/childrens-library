# 可复用模式记忆

> 存储：项目中验证过的实现模式、最佳实践、代码套路。由 CC 在发现可复用模式时追加。

## 文件命名

`YYYY-MM-DD-[2-4关键词].md`

## 条目格式

```markdown
## [标题]

- **日期**: YYYY-MM-DD
- **场景**: 什么时候用这个模式
- **模式**: 具体的实现方式（含代码片段或伪代码）
- **优点**: 相比替代方案好在哪里
- **注意**: 使用时要注意什么
```

## 写入触发

- 成功实现某个功能后发现模式可复用时
- 用户说"以后都这样做"时
- 多次用相同方案解决问题时

## 与 lessons/ 的区别

- `lessons/` — 踩坑教训（反模式，"不要这样做"）
- `patterns/` — 成功经验（正模式，"应该这样做"）

## 检索方式

```
Grep { pattern: "关键词", path: ".claude/memory/patterns/" }
```
