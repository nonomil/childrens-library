# 嵌入式 / 工业系统专家

> 来源：VoltAgent embedded-systems、SYSGO 实时响应、IEC 61508/ISO 26262、MISRA

## 审查维度

| 维度 | 检查项 |
|------|--------|
| 实时约束 | 所有任务在 WCET 内完成；中断延迟在界内；无优先级反转（优先级继承/天花板协议）；ISR 中无阻塞操作；栈大小按最坏嵌套深度计算 |
| 资源限制 | RAM/Flash 预算内；无界缓冲区/队列已限制；DMA 缓冲区大小已验证；功耗在范围内 |
| 看门狗/容错 | 看门狗配置正确且不可意外禁用；子故障有降级策略；关键输出有故障安全状态；安全组件有冗余；心跳/保活监控 |
| 安全标准 | MISRA C/C++ 合规（静态分析）；IEC 61508 / ISO 26262 需求追踪；编码标准文档化 |
| 硬件交互 | 寄存器访问原子性；`volatile` 正确用于内存映射 I/O；ISR 与主循环无竞态；外设初始化顺序正确 |
| 诊断追踪 | 运行时追踪可用；日志级别可配置（无需重编译）；错误码定义且文档化；事后诊断可用 |

## 实时性关键检查

1. **WCET 分析**：安全关键路径必须静态分析最坏执行时间
2. **优先级反转**：必须使用优先级继承或天花板协议（如 `pthread_mutexattr_setprotocol`）
3. **ISR 规则**：ISR 中禁止阻塞操作（malloc、printf、mutex lock）
4. **栈深度**：静态计算最深调用链的栈消耗 + 中断嵌栈
5. **动态内存**：初始化后禁止 `malloc`/`new`（碎片化导致不确定延迟）

## 安全标准映射

| 标准 | 适用场景 | 关键要求 |
|------|---------|---------|
| MISRA C:2012 | 汽车/医疗 | 限制语言子集，静态分析 |
| AUTOSAR C++14 | 汽车 | RAII 强制，禁用异常 |
| IEC 61508 | 功能安全（通用） | SIL 等级，V 模型开发 |
| ISO 26262 | 汽车功能安全 | ASIL 等级，FMEA/FTA |
| IEC 62304 | 医疗设备软件 | 软件安全分类，单元测试 |

## 故障模式检查

- 所有输出有故障安全默认值
- 看门狗超时 < 最长合法任务时间
- 通信断开有超时检测
- 电源异常有保存/恢复机制
- 传感器故障有合理性检查
