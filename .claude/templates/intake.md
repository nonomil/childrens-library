# Intake — 需求收集模板

> 收到新需求时，Agent 应引导用户填写以下字段。
> 缺少带 * 号的字段时，禁止进入执行阶段。

## 基本信息

- **场景类型**：[research / feature / bugfix / refactor / optimization]
- **目标描述** *：[一句话描述要达成什么]
- **改动范围**：[哪些文件/模块]
- **不可碰的范围**：[哪些文件不能改]

## 验证条件

- **评估命令** *：[怎么验证改动是正确的，如 pytest / python script.py]
- **成功标准** *：[具体的可判定条件，如 "F1 >= 0.90" / "所有测试通过"]
- **约束条件**：[必须满足的额外约束，如 "检测时间 < 0.3s" / "不引入新依赖"]

## 执行参数

- **优先级**：P0（紧急）/ P1（重要）/ P2（一般）
- **复杂度估计**：简单（≤3 文件）/ 中等 / 复杂
- **执行模式**：standard（人机协作）/ autonomous（自主迭代，仅限可量化目标）
- **预算**：[最大迭代次数 / 时间限制]

## 启动检查

- [ ] 目标描述已填写
- [ ] 评估命令可执行
- [ ] 成功标准可判定
- [ ] （自主模式）目标可量化为单一数值指标
