# Industrial UI Design

用工业软件的方式设计桌面界面：操作员定位快、图像信息优先、长时间运行不疲劳。

## 适用场景

- 机器视觉或工业检测软件设计主工作台
- Qt / PySide / PyQt 桌面端工业风布局和主题系统
- 需要"图像居中、参数停靠、日志下沉"规范
- 输出可复用的工业 UI 设计流程与检查清单

不适用于纯 Web 后台、营销站点或轻交互展示页。

## 核心流程

1. **定工作台骨架**：菜单栏 → 左侧任务导航 → 中央视图区 → 右侧参数区 → 底部运行区
2. **定主题系统**：深色（值守）+ 浅色（调试/培训/截图）
3. **定页面职责**：中间只放图像/状态/结果，右侧只放参数/动作/导出
4. **补验证**：线程不阻塞 UI、主题可切换、日志统计分区清晰

## 设计规则

- 以图像为中心，不做表单墙
- 参数区必须停靠，不挤占中央视图
- 告警颜色 + 文本/图标双层信号，不依赖纯色块
- 长时任务必须下放到后台线程
- 所有页面遵守同一套布局骨架

## 验证清单

- [ ] 是否存在 `文件 / 设置 / 说明` 菜单
- [ ] 是否支持深色/浅色主题切换
- [ ] 是否保留左中右三栏与底部运行区
- [ ] 是否以 QThread 或等效机制处理长任务
- [ ] 是否有 smoke test 约束窗口结构
