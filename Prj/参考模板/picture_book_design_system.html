04 · 字体与排版

Typography System

中文使用系统圆体，英文 / 数字用 Nunito（圆润无衬线）。绝对不用细体、斜体、装饰字体。

中文字体方案：系统优先用 PingFang SC / 华文圆体 / Microsoft YaHei，正文 fallback 到 sans-serif。英文标题用 Nunito（Google Fonts，免费）。数字计数用 Nunito，不要 monospace。

06 · 插画风格规范

Illustration Style Guide

全部使用 SVG 扁平插画，圆润形状，厚线条轮廓，饱和色彩，避免真实照片和复杂贴图。

圆润动物角色
大眼睛、厚轮廓、超圆形体
扁平场景背景
分层色块、无透视、简化形状
奇幻魔法元素
星光、渐变光晕、饱和紫色系
SVG 插画规范：所有主角圆形度 ≥ 60%（用 circle/ellipse 为主），轮廓线 stroke-width 2–3px，配色取自系统色板，不引入第三方图片。阴影用 opacity 0.15 叠色块代替 filter: drop-shadow。

08 · 设计规范

Do / Don't

避免这些常见错误，是让绘本网站从"普通"变"精美"的关键差距。

✅ Do · 这样做
✓
按钮 hover 时 scale(1.05~1.08) + 上移 2–3px，有弹跳感
✓
卡片圆角 border-radius ≥ 20px，统一且一致
✓
每个 CTA 按钮有对应颜色的 box-shadow（半透明）
✓
正文行距 line-height ≥ 1.8，阅读舒适
✓
插画用 SVG 扁平风格，主角有大眼睛、厚轮廓
✓
配色用系统色板，轻/中/深三档成套使用
✓
书封面用纯色渐变区分，emoji 做主视觉占位
❌ Don't · 避免这样
✗
按钮没有 hover 效果，点击无任何视觉反馈
✗
圆角忽大忽小，border-radius: 4px 和 20px 混用
✗
所有按钮用同一个灰色或白色，没有层级
✗
正文字号小于 14px，行距 ≤ 1.4
✗
直接用真实照片做插画，风格割裂
✗
随意取色，没有品牌一致性
✗
书封面统一用白底灰字，没有辨识度

🏠 首页实现提示词
# PicBook 儿童绘本网站 - 首页实现规范

## 技术栈
- 纯 HTML5 + CSS3 + 原生 JS（无框架依赖）
- 字体：Google Fonts Nunito（400/700/800/900）
- 图标：纯 SVG 或 Unicode emoji
- 插画：内联 SVG，扁平风格

## CSS 变量（必须在 :root 中定义）
--cream: #FFF8EE          /* 全局背景 */
--orange: #FF6B35          /* 主品牌色 */
--orange-light: #FFE4D6   /* 浅橙，用于 hover bg */
--blue: #4A90D9            /* Hero 背景、链接 */
--green: #5BAD6F           /* 成就、完成状态 */
--yellow: #FFD166          /* 收藏、标签 */
--ink: #2D2D2D             /* 正文 */
--ink-muted: #9A9A9A      /* 辅助信息 */

## 圆角规范（所有卡片/容器必须用变量）
--radius-sm: 12px   /* 小元素 badge/tag */
--radius-md: 20px   /* 卡片、输入框 */
--radius-lg: 28px   /* 大容器、Hero */
--radius-xl: 40px   /* 特殊圆形按钮 */

## 按钮规范
所有主 CTA 按钮必须有：
border-radius: 28px;
padding: 14px 28px;
font-weight: 800;
transition: transform 0.15s, box-shadow 0.15s;
box-shadow: 0 4px 16px rgba(主色, 0.35);
hover 效果：
transform: scale(1.06) translateY(-2px);
box-shadow: 0 8px 24px rgba(主色, 0.45);

## 书籍卡片规范
结构：封面图（彩色渐变背景+emoji）+ 书名 + 元数据 + 年龄标签
封面高度: 100–140px
卡片 border-radius: 20px
box-shadow: 0 6px 20px rgba(0,0,0,0.10)
hover：
transform: translateY(-4px);
box-shadow: 0 12px 32px rgba(0,0,0,0.16);
transition: 0.2s ease;

## Hero Banner 规范
background: linear-gradient(135deg, #4A90D9, #6AABF2)
min-height: 300px
左侧：大标题（font-size≥36px，weight 900，白色）+ 2个按钮
右侧：SVG 书本/角色插画或装饰物
📖 阅读页实现提示词
# 绘本阅读页 Reader Page 实现规范

## 布局结构
1. 顶部工具栏（高度 60px，深色背景 #1A1A2E）
   - 左：书名 + 进度信息
   - 右：控制按钮（字号/音频/全屏）+ 退出按钮

2. 双页展开区（grid: 1fr 1fr，min-height 400px）
   - 左页：浅色背景，SVG 插画居中（宽度 80%，居中）
   - 右页：奶油白背景 #FFF8EE，阅读正文

3. 底部页码导航（深色背景，圆点居中）
   - 当前页圆点：橙色 #FF6B35，scale 1.3
   - 其他页圆点：半透明白色

## 正文排版
font-size: 18–20px
line-height: 1.85
font-family: 'Nunito Sans', 'PingFang SC', sans-serif
关键词/角色名：用 <em> 或 span 标蓝色 #4A90D9，font-weight 700

## 翻页按钮
上一页：浅蓝背景 #D6EAFA，蓝色文字
下一页：橙色背景 #FF6B35，白色文字
hover 动效：上一页向左位移 3px，下一页向右 + scale 1.04

## SVG 插画规范
- 必须用 viewBox，不用 width/height 固定值
- 主角圆形度：70% 以上用 circle/ellipse
- 表情：大眼睛（两个白色高光点），嘴巴用 path 弧线
- 背景分层：天空层 + 地面层 + 中景 + 主角
- 颜色严格取自 CSS 变量色板
💡 使用技巧：把上面的规范 + 本文档的 HTML 源码截图一起发给 Claude Code，让它"照这个改内容"而不是"从头设计"，成功率和质量会大幅提升。尤其是 SVG 插画部分，直接复制阅读页的 SVG 代码让它修改角色和场景，比重新生成效果好很多。
