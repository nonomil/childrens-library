## 二、各课件详细分析

### 2.1 gears-transmission-v2.html（机械课件）⭐ 最优

**视觉设计 (9/10)**
- 配色方案专业：深蓝 `#1a365d` + 琥珀 `#d97706` + 鼠尾草绿 `#4a7c59`，三色对比鲜明
- CSS变量系统完善（`:root` 定义 15+ 个语义化变量）
- 全屏 Hero 封面 + 纸质纹理背景，高级感强
- 页面交替渐变背景增加视觉节奏感

**交互体验 (9/10)**
- Canvas 实时渲染齿轮旋转，支持拖拽交互
- 齿轮配对、链条传动、连杆机构等 6 个交互式知识模块
- 8 个游戏模块（齿轮配对、修理机器、齿轮接龙等）
- 实时反馈：Sparkle 特效、Correct/Try again 提示
- 滑块控制参数（齿数、链条松紧度），参数化探索

**内容结构 (8/10)**
- 知识递进清晰：基础→配对→链条→连杆→传动带→实验室
- 游戏难度分级（Easy/Medium/Hard）
- 最终测验 + 知识总结页

**代码质量 (9/10)**
- CONFIG + ENGINE 分离架构，可复用性强
- 模块化清晰：工具函数、Canvas 渲染、游戏引擎独立
- 响应式适配完善（480px 断点）
- 触摸/鼠标统一事件处理

### 2.2 math-01-counting.html（数学课件）

**视觉设计 (7/10)**
- 蓝色渐变背景 `#e3f2fd → #bbdefb`，清新明亮
- 圆角卡片 + 投影层次感好
- 有 AI 生成插图（webp 格式），视觉内容丰富
- 缺点：色彩系统未统一提取为 CSS 变量

**交互体验 (7/10)**
- 翻页动画流畅（GSAP 驱动）
- 数羊计数、手指点数、数字卡片等互动
- 涂色、找不同、排序等练习类型丰富
- 语音朗读（speechSynthesis）
- 缺点：部分交互无动画反馈，排序交换无过渡效果

**内容结构 (8/10)**
- 故事线完整：方块世界→数数→手指→认识数字→练习→闯关→庆祝
- 难度递进合理
- 学习目标清晰列出

**代码质量 (7/10)**
- 使用共享 `courseware.css` + `courseware.js`
- CSS 全局样式内联，代码量大（460+ 行 CSS）
- JS 用 IIFE 封装，变量命名规范
- 缺点：练习逻辑分散，难以复用

## 三、新旧课件差异对比

| 维度 | 旧课件（语数外+机械） | 新课件（绘本/故事） |
|------|----------------------|---------------------|
| **架构** | 共享 CSS/JS + 独立页面逻辑 | 单文件自包含，无共享 |
| **视觉** | AI 插图 + 丰富色彩系统 | 无插图，emoji 为主 |
| **交互** | Canvas 动画、拖拽、滑块、配对 | 仅翻页按钮 |
| **语音** | speechSynthesis 朗读 | 无 |
| **响应式** | 完善的移动端适配 | 无 |
| **触摸** | 支持滑动翻页 | 无 |
| **练习** | 多种题型（选择、配对、填空、描红） | 简单选择题 |
| **动画** | GSAP 翻页、confetti 庆祝 | 仅 CSS 星星/树叶动画 |
| **代码量** | 800-1200 行 | 270-290 行 |
| **可维护性** | 模块化，易扩展 | 单体，难复用 |

**核心差距**：新课件是"故事阅读器"，旧课件是"互动学习工具"。新课件缺少教育课件应有的所有核心交互能力。

## 四、按优先级排序的优化建议

### P0 — 必须修复（影响基本可用性）

1. **新课件增加语音朗读**
   - 中文故事：接入 `speechSynthesis`（zh-CN）
   - 英文故事：接入 `speechSynthesis`（en-US），这对英语学习至关重要
   - 参考 math/english 课件的 `speakText()` 实现

2. **新课件增加触摸滑动翻页**
   - 参考 `courseware.js` 的 `initSwipe()` 或 math 课件的触摸处理

3. **新课件增加响应式布局**
   - 添加 `@media` 断点适配手机/平板

### P1 — 重要优化（提升学习效果）

4. **新课件增加互动练习**
   - 中文绘本：增加汉字配对、看图选词等练习
   - 英文故事：增加词汇学习页、句型练习、选择题测验
   - 参考 QuizEngine 类（已定义但未使用）

5. **新课件增加 AI 插图**
   - 每页添加一张 AI 生成的配图（webp 格式）
   - 参考 math/english 课件的 `<img src="images/...">` 模式

6. **新课件增加键盘导航**
   - ArrowLeft/Right 翻页

### P2 — 体验优化（提升专业感）

7. **统一视觉规范**
   - 所有课件使用 CSS 变量系统（参考 gears 的 `:root` 定义）
   - 统一圆角、阴影、字体大小规范

8. **新课件增加 confetti 庆祝效果**
   - 完成故事/测验后触发
   - 参考 `courseware.js` 的 `celebrate()`

9. **新课件增加进度指示**
   - 页面导航点（dots）+ 页码显示

### P3 — 架构优化（长期维护）

10. **将新课件迁移到模板系统**
    - 使用 `StoryEngine` + `QuizEngine` 标准组件
    - 复用 `courseware.css` 基础样式

11. **提取共享交互组件**
    - 语音模块、翻页模块、触摸模块已部分在 `courseware.js` 中
    - 需要确保新课件正确引用

## 五、语数外三科差异化策略

### 数学课件 — 强化"动手操作"

| 策略 | 说明 |
|------|------|
| **Canvas 交互** | 像齿轮课件那样，用 Canvas 做数学可视化（数轴、几何图形变换） |
| **参数化探索** | 滑块控制数字/形状，实时看到变化 |
| **即时反馈** | 每步操作都有视觉反馈（正确/错误动画） |
| **难度递进** | 每个知识点分 3 级难度，自动适应 |

### 英语课件 — 强化"听说读写"

| 策略 | 说明 |
|------|------|
| **语音优先** | 每个单词/句子都可点击发音，支持跟读 |
| **对话模拟** | 用气泡对话模拟真实场景，支持角色切换 |
| **词汇卡片** | 翻转卡片学习新词，支持 MP3 音频 |
| **歌曲/韵律** | 增加英文儿歌页面（参考 english-01 的 Sing 页面） |
| **文化拓展** | 增加西方文化小知识板块 |

### 语文课件 — 强化"书写与文化"

| 策略 | 说明 |
|------|------|
| **田字格描红** | Canvas 实现汉字描红（参考 chinese-01 的 trace 功能） |
| **字源演变** | 象形→甲骨文→金文→篆书→楷书的演变展示 |
| **古诗联动** | 每课关联一首古诗，增强文化浸润 |
| **组词造句** | 从单字→组词→造句的渐进式练习 |
| **书法欣赏** | 增加名家书法展示 |

## 六、统一设计规范建议

### 6.1 色彩系统

```css
:root {
  /* 学科主色 */
  --math-primary: #1E88E5;     /* 数学蓝 */
  --math-secondary: #42A5F5;
  --english-primary: #43A047;  /* 英语绿 */
  --english-secondary: #66BB6A;
  --chinese-primary: #C62828;  /* 语文红 */
  --chinese-secondary: #EF5350;
  --stem-primary: #1A365D;     /* STEM 深蓝 */
  --stem-accent: #D97706;

  /* 语义色 */
  --success: #4CAF50;
  --error: #F44336;
  --warning: #FF9800;
  --info: #2196F3;

  /* 中性色 */
  --bg-primary: #FAFAFA;
  --bg-card: #FFFFFF;
  --text-primary: #333333;
  --text-secondary: #666666;
  --text-muted: #999999;
  --border: #E0E0E0;
}
```

### 6.2 排版规范

| 元素 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 封面标题 | 32-36px | 800 | 课件标题 |
| 章节标题 | 20-22px | 700 | 每页标题 |
| 正文 | 15-16px | 400 | 故事文本 |
| 说明文字 | 13-14px | 400 | 辅助说明 |
| 按钮文字 | 14-16px | 600 | 交互按钮 |
| 反馈文字 | 14-15px | 600 | 正确/错误提示 |

### 6.3 间距与圆角

```css
:root {
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 12px;
  --space-lg: 16px;
  --space-xl: 24px;
  --space-2xl: 32px;

  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-xl: 24px;
  --radius-full: 9999px;
}
```

### 6.4 组件规范

| 组件 | 样式要求 |
|------|----------|
| **卡片** | `border-radius: 16px; padding: 16px; box-shadow: 0 2px 12px rgba(0,0,0,0.06)` |
| **按钮** | `min-width: 44px; min-height: 44px; border-radius: 50%（圆形）或 20px（胶囊）` |
| **导航栏** | 固定底部，毛玻璃效果，包含：上一页 / 导航点 / 语音 / 下一页 |
| **反馈弹窗** | 居中显示，0.5s 淡入，0.8s 后自动消失 |
| **语音按钮** | 播放时有脉冲动画（`speakPulse`） |

### 6.5 交互规范

| 交互 | 规范 |
|------|------|
| **翻页** | 支持按钮点击、触摸滑动、键盘方向键 |
| **语音** | 每个可发音元素点击即读，播放时按钮有动画 |
| **练习反馈** | 正确 → 绿色 + ✓，错误 → 红色 + ✗ + 正确答案高亮 |
| **庆祝效果** | 完成关键节点触发 confetti（60 粒子，1.5s 动画） |
| **触摸目标** | 所有可点击元素最小 44×44px |

## 七、总结

### 当前优势
1. **齿轮课件**是标杆级作品，架构、视觉、交互俱佳
2. **语数外三科课件**各有特色，内容结构完整
3. **共享组件** `courseware.js` 提供了基础能力

### 核心问题
1. **新生成课件质量远低于预期**，缺少语音、触摸、响应式、插图、练习等核心能力
2. **视觉风格不统一**，新旧课件差异明显
3. **共享组件利用率低**，新课件未引用 `courseware.css/js`

### 下一步行动
1. **立即**：修复新课件的 P0 问题（语音、触摸、响应式）
2. **本周**：为新课件添加练习和插图
3. **下周**：统一设计规范，迁移新课件到模板系统
4. **持续**：建立课件质量检查清单，每个新课件发布前过审
