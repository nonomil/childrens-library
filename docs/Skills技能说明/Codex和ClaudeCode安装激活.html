Portable Copy

方便拷贝到新电脑

建议一起带走的最小目录

如果你准备把这套工具复制到另一台电脑，建议至少保留下面这些内容放在同一个根目录里。脚本会依赖相对路径找到网页和配置模板。

  • `update_codex_config.bat`
  • `update_codex_config.ps1`
  • `update_codex_config.json`
  • `docs 文件夹`

复制之后怎么开始

复制到任意目录都可以，不需要固定用户名，也不需要固定盘符。双击 `update_codex_config.bat` 后，如果想先看文档，就在菜单里选 `4` 打开本地说明网页；准备激活时再选 `1`、`2` 或 `3`。

网页入口、配置模板和 PowerShell 辅助脚本都会从当前文件夹自动定位。

Shared Prerequisites

共同前置条件

1. Install Node.js

无论装 Codex 还是 Claude Code，第一步都先装 Node.js。建议先确认 `node` 和 `npm` 已经能在终端里运行。

Download 
https://nodejs.org/dist/v24.12.0/node-v24.12.0-x64.msi
Verify 
node -v
npm -v

2. Fix PowerShell policy if needed

如果 PowerShell 阻止脚本执行，可以先放开当前用户的执行策略。只需要做一次。

PowerShell 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Tool Paths

按需求选择安装路线

Option A

Codex CLI

如果你只打算使用 Codex，那只装 Codex CLI 就够了。当前这套文档默认考虑 `OpenAI Codex 使用 智谱 API` 的场景，所以建议直接用镜像源安装。

Install Codex 
npm install -g @openai/codex --registry=https://registry.npmmirror.com/
codex --version

Option B

Claude Code CLI

如果你只打算使用 Claude Code，那只装 Claude Code CLI 就行。后面的激活页里，用模式 `2`。

Install Claude Code 
npm install -g @anthropic-ai/claude-code
claude --version

Option C

Install Both

如果你要在同一台机器上切换使用两个工具，推荐一次装齐，后续只需要切换激活模式。

Install Both 
npm install -g @anthropic-ai/claude-code
npm install -g @openai/codex --registry=https://registry.npmmirror.com/
claude --version
codex --version
