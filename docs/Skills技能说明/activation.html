Activation

只做配置切换，不再手改文件

这一页只讲激活。直接 Double-click `update_codex_config.bat`，然后 choose option 1, 2, or 3。 No command typing required。脚本会优先自动读取 `update_codex_config.json`，只有缺少值时才会提示输入。 如果你只是先想看文档，可以在同一个菜单里选择 `4` 打开本地说明网页。 激活成功后，脚本还会自动打开 `Codex` 和 `Claude` 命令窗口，方便你马上测试。

Codex Activation

Codex Activation

Mode 1: Codex-ChatGPT

适合直接连接 OpenAI。脚本会写入 `~/.codex/auth.json` 和 `~/.codex/config.toml`。

  • Target file: `~/.codex/auth.json`
  • Target file: `~/.codex/config.toml`
  • Provider: `openai`
  • 适合有标准 OpenAI Key 的场景

操作方式：双击 `update_codex_config.bat` 后，在菜单中选择 `1`。

Mode 3: Codex-Zhipu

也是 Codex，但这里已经改成直接使用智谱 API 的配置写法，而不是旧的代理模式。仍然写入 Codex 的配置文件。

  • Target file: `~/.codex/auth.json`，内容是 `{"OPENAI_API_KEY": null}`
  • Target file: `~/.codex/config.toml`
  • Provider: `BigModel`
  • Model: `GLM-5.1`
  • Base URL: `https://open.bigmodel.cn/api/coding/paas/v4`
  • 智谱 GLM 注册入口：`bigmodel.cn`

操作方式：双击 `update_codex_config.bat` 后，在菜单中选择 `3`。如果 `update_codex_config.json` 里已经填好智谱 key，通常不需要再手动输入。

Docs Shortcut

菜单里的网页入口

Mode 4: 打开本地说明网页

如果你把整个文件夹复制到了新电脑，还没决定先装哪一个工具，可以先双击脚本，在菜单中选择 `4`，直接打开 `docs/index.html`。这样不用先找 Markdown，也不用手动输命令。

脚本会自动按当前用户目录和脚本所在目录识别路径，所以用户名变化、文件夹改名或换盘符时，通常都不需要手改脚本。

Quick Test

激活后立刻测试

自动打开两个命令窗口

脚本在完成激活后，会自动打开两个命令窗口：一个运行 `Codex`，一个运行 `Claude`。这样你不用自己再去找终端，也不用手动再敲启动命令。

输入这一句测试

窗口打开后，直接输入：`你是什么模型`。这样能最快确认当前 CLI 已经接入了哪一个模型、是不是已经切到了你刚刚配置的线路。

如果某个命令还没有安装，脚本会提示未检测到该命令，对应窗口不会强行打开。

Claude

Claude Code Activation

Mode 2: ClaudeCode-Zhipu

这个模式只服务 Claude Code。脚本会写入 `~/.claude/settings.json`，把 Anthropic 兼容环境变量一并配置好。

  • Target file: `~/.claude/settings.json`
  • Writes `ANTHROPIC_AUTH_TOKEN`
  • Writes `ANTHROPIC_BASE_URL`
  • 适合 Claude Code 走智谱 Anthropic 兼容接口

操作方式：双击 `update_codex_config.bat` 后，在菜单中选择 `2`。

Interactive Usage

交互模式怎么用

Double-click

Double-click `update_codex_config.bat`，脚本会弹出中文菜单。你只需要选择模式。只要 `update_codex_config.json` 填好了，对应模式会直接自动读取。

No command typing required。只有在配置文件里缺值时，脚本才会退回到交互输入；如果只是想看说明，就在菜单中选择 `4`。激活后还会自动打开 Codex 和 Claude 命令窗口。

What happens after activation

脚本会自动识别当前用户目录，按模式覆盖对应文件，并自动按当前用户目录和脚本所在目录识别路径。用户名变化时，不需要修改脚本路径。写入完成后，还会自动打开 Codex 和 Claude 命令窗口，方便你马上输入 `你是什么模型` 做检查。
