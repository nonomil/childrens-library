Skills

推荐 skills、用途和安装路线

这一页把项目文档里提到的 skills 拆成单独卡片。每个卡片都写了用途、适合谁用，以及 How to install。 这里不强调你自己敲安装命令，而是提示你直接复制下面的话给 AI。

Recommended Skills

六个值得优先了解的 skills

Frontend Design

用来解决前端页面“AI 味太重”的问题，强制模型在排版、字体、色彩和动效上做出更明确的设计选择。

How to install：复制下面的话给 AI，让它帮你安装。适合经常做页面、数据看板、小工具界面的人。

Copy this to your AI 
请帮我安装 Frontend Design skill。
如果它在官方 curated skills 里，请直接安装；
如果不在，请从对应 GitHub 仓库安装。
安装完成后提醒我重启 Codex。
Open repo

Office Four-Pack

把 `docx`、`xlsx`、`pdf`、`pptx` 作为一组文档处理能力来看，能显著提升办公文档生成和修改质量。

How to install：建议让 AI 按需安装，不一定一次装满四个。

Copy this to your AI 
请帮我安装办公文档相关 skills，包括 docx、xlsx、pdf、pptx。
请优先使用 skill-installer，
如果某个 skill 需要 GitHub 仓库安装，也请一并处理。
Open repo

Web Access

适合需要真实联网、浏览器操作和带登录态读取站内内容的场景，比普通搜索更强。

How to install：这是第三方 skill，更适合直接把 GitHub 地址复制给 AI。

Copy this to your AI 
请使用 skill-installer，
从 GitHub 仓库 https://github.com/eze-is/web-access/ 安装 Web Access skill。
安装完成后提醒我重启 Codex。
Open repo

PUA

适合在 Agent 明显摆烂、陷入重复尝试却不愿继续推进时使用，核心作用是强制它换策略。

How to install：第三方 skill，直接复制给 AI 让它处理更省心。

Copy this to your AI 
请使用 skill-installer，
从 GitHub 仓库 https://github.com/tanweai/pua 安装 PUA skill。
安装完成后提醒我重启 Codex。
Open repo

Claude-mem

提供长期记忆和跨会话检索，适合上下文很长、项目持续时间很久的任务。

How to install：第三方 skill，推荐直接把仓库和需求一起交给 AI。

Copy this to your AI 
请使用 skill-installer，
从 GitHub 仓库 https://github.com/thedotmack/claude-mem 安装 Claude-mem。
安装完成后提醒我重启 Codex。
Open repo

Skill-Creator

它不只是一个可安装 skill，更是把你自己的流程沉淀成 skill 的入口，长期价值最高。

How to install：很多环境里它已经内置；如果没有，再让 AI 判断是否需要补装。

Copy this to your AI 
请帮我检查当前环境里是否已经有 skill-creator。
如果没有，请用合适的来源帮我安装；
如果已经有，请告诉我怎么开始使用它。
Open reference
