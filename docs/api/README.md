# docs/api/ — 本地 API 文档库

> 供 AI 上下文注入的第三方库 API 文档缓存。

## 目录用途

存放项目依赖的第三方库 API 文档片段。只存项目实际用到的部分，不全量下载。

配合 `doc-ref` skill 使用：任务涉及外部库时自动检索和注入。

## 目录结构

```
docs/api/
├── README.md              # 本文件
├── index.md               # 索引表：库名 | 版本 | 索引时间 | 本地路径
└── [sdk-name-version]/    # 各 SDK 文档
    └── [topic].md         # 按主题拆分的文档片段
```

## 索引格式

见 `index.md`，包含：库名、版本号、索引时间、本地路径、备注。

## 生成时机

- 任务涉及不熟悉的第三方 API 且本地无索引 → 自动触发 research workflow 抓取
- 用户说"索引 [SDK] 文档到本地" → 手动触发
- 用户说"更新 [库名] 文档索引" → 手动触发更新

## 支持的文档类型

- 公开 SDK/API（PyPI/npm 官方文档）
- 内部 SDK 文档（手动放入目录）
- 协议/规范文档（如 HTTP API spec）
