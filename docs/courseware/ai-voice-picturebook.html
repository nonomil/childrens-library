04 情绪控制

情绪让角色活起来

同一句台词，5种不同的情绪表达

孩子会不会入戏，差就差在声音的情绪上。

演示：「你怎么能这样！」

😊 开心地 — 调皮玩笑 😠 生气地 — 真的生气了 😲 惊讶地 — 不敢相信 🥺 委屈地 — 快哭了 😨 害怕地 — 瑟瑟发抖

代码示例

# 为同一句台词生成不同情绪的版本 text = "你怎么能这样！" emotions = {
"happy": "开心地笑着说：" + text,
"angry": "生气地大声说：" + text,
"surprised": "惊讶地捂住嘴：" + text,
"sad": "委屈地低下头：" + text,
"scared": "害怕地往后退：" + text,
}

for emotion, prompt in emotions.items():
minimax_tts(prompt, voice_id="female-01",
output=f"{emotion}.mp3")

🎭 技巧

在文本前加情绪副词（"开心地"、"生气地"、"惊讶地"），AI会自动调整语调和节奏。

05 完整代码

一键生成有声绘本

Python + MiniMax API，30行代码搞定

import requests

class VoiceBook:
def __init__(self, api_key):
self.headers = {
"Authorization": f"Bearer {api_key}",
"Content-Type": "application/json"
}


def tts(self, text, voice_id, output):
"""生成单句语音"""
url = "https://api.minimax.chat/v1/t2a_v2"
payload = {
"model": "speech-01",
"text": text,
"voice_id": voice_id
}
resp = requests.post(url, headers=self.headers, json=payload)
audio_url = resp.json()["audio_url"]
# 下载并保存
open(output, "wb").write(requests.get(audio_url).content)

def bgm(self, desc, duration, output):
"""生成背景音乐"""
url = "https://api.minimax.chat/v1/music_generation"
payload = {
"description": desc,
"duration": duration
}
resp = requests.post(url, headers=self.headers, json=payload)
audio_url = resp.json()["audio_url"]

06 实用技巧

让效果更好的小技巧

🎯 语速调节

  • 小孩角色：speed 0.85，慢一点更可爱
  • 旁白：speed 1.0，正常速度
  • 紧张场景：speed 1.2，加快制造紧张感

🎭 声音克隆技巧

  • 录制 30秒以上 的清晰音频
  • 环境要安静，不要背景音乐
  • 用日常讲故事的语气，不要太刻意
  • 克隆后先试几句，不自然就重录

🎵 BGM 描述技巧

  • 描述 场景 + 乐器 + 情绪，如"温馨森林冒险，轻柔钢琴，梦幻"
  • 时长建议 30-60秒，循环播放
  • 混合时BGM音量降到 20%，不要盖过人声

⚠️ 注意

API 调用有费用，大量生成前先小规模测试。MiniMax 新用户通常有免费额度。
