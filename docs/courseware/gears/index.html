什么是齿轮？
齿轮就像一个个"小牙齿"围成的圆饼饼！
它们手拉手转圈圈，就能把力气传给别人 🤝
🦷 有牙齿 🔄 会转圈 🤝 传力气 🔢 大小不同
🔄
齿轮碰齿轮
两个齿轮牙齿咬牙齿，一个转，另一个也转！
方向是 相反的 哦～左边往右，右边往左 🤯
👆 点下面的小人都可以调速哟！
🦷 牙齿咬牙齿 ↔️ 方向相反 ⚡ 一起转
⛓️
链条传动
链条就像一条长长的"小铁链"，
把两个齿轮连起来，力气就能传好远好远！
👆 点一下链条让它动起来！
🚲
自行车就是靠链条传动的！
