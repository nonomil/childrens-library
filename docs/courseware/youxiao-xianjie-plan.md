# 幼小衔接三科极简规划

## 核心理念

幼小衔接不是提前学小学知识，而是**培养学习习惯、建立学科兴趣、储备基础能力**。用"极简"思路，每天20分钟，搞定三科核心任务。

---

## 第一科：语文（每天10分钟）

### 核心目标

| 能力 | 具体指标 | 方法 |
|------|---------|------|
| **识字量** | 500-800个常用字 | 生活中认字（路牌、包装、绘本） |
| **表达能力** | 能说完整句子，描述一件事 | 每天"今天三件事"口头表达 |
| **阅读兴趣** | 每天读绘本≥20分钟 | 亲子共读 + 指读 |
| **书写准备** | 正确握笔姿势，能写自己名字 | 描红本 + 沙画字 |

### 极简规划

```
每天10分钟 = 5分钟识字 + 5分钟阅读
```

**识字游戏**（5分钟）：
- 字卡配对：准备20张常见字卡，玩"找朋友"游戏
- 生活识字：散步时认路牌、店名、车牌
- 绘本指读：读绘本时指着一个字一个字读

**亲子阅读**（5分钟）：
- 固定睡前时间
- 孩子选书，家长读
- 读完后问："故事讲什么？最喜欢谁？为什么？"

---

## 第二科：数学（每天10分钟）

### 核心目标

| 能力 | 具体指标 | 方法 |
|------|---------|------|
| **数感** | 1-100数数，理解10以内加减 | 实物操作（积木、手指） |
| **分类** | 按颜色/大小/形状分类 | 整理玩具时练 |
| **比较** | 大小、多少、高矮 | 生活中的比较 |
| **空间** | 上下左右、前后 | 藏宝游戏 |

### 极简规划

```
每天10分钟 = 5分钟数感 + 5分钟游戏
```

**数感训练**（5分钟）：
- 数数：上下楼梯数台阶、吃葡萄数颗数
- 点数：拿5个积木，一个一个数
- 简单加减："你有3块糖，给妈妈1块，还剩几块？"

**数学游戏**（5分钟）：
- 扑克牌比大小
- 七巧板拼图
- 超市购物（模拟付钱）

---

## 第三科：英语（每天5-10分钟）

### 核心目标

| 能力 | 具体指标 | 方法 |
|------|---------|------|
| **听力** | 听懂简单指令和日常对话 | 听儿歌、看动画 |
| **口语** | 会说简单单词和短句 | 跟读、日常对话 |
| **兴趣** | 不排斥英语，觉得好玩 | 游戏化、场景化 |

### 极简规划

```
每天5-10分钟 = 3分钟儿歌 + 3分钟动画 + 2分钟对话
```

**儿歌熏听**（3分钟）：
- Super Simple Songs
- 磨耳朵，不用求懂，培养语感

**动画输入**（3分钟）：
- Peppa Pig（小猪佩奇）
- 看画面理解意思，不用翻译

**日常对话**（2分钟）：
- "What's this?" "It's an apple."
- 吃饭时、穿衣时，用英语说物品名

| 时间 | 语文 | 数学 | 英语 |
|------|------|------|------|
| 周一 | 识字游戏 | 数感训练 | 儿歌 |
| 周二 | 亲子阅读 | 数学游戏 | 动画 |
| 周三 | 识字游戏 | 数感训练 | 日常对话 |
| 周四 | 亲子阅读 | 数学游戏 | 儿歌 |
| 周五 | 识字游戏 | 数感训练 | 动画 |
| 周六 | 自由阅读 | 超市购物 | 家庭英语角 |
| 周日 | 复习本周字 | 复习数字 | 复习单词 |

**每天总计：20-30分钟**

---

## 注意事项

1. **不要提前学课本**：避免孩子上小学后觉得"我都会了"而不听讲
2. **兴趣第一**：玩中学，不要变成"刷题"
3. **坚持比强度重要**：每天20分钟 > 周末突击2小时
4. **家长陪伴**：幼小衔接是亲子共同成长的过程
5. **尊重节奏**：每个孩子发育节奏不同，不要比较
