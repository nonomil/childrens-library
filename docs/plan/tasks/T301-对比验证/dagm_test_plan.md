# DAGM 2007 测试方案（v2）

> 目标：在 DAGM 真实工业纹理数据上验证 PLDD pipeline，排除合成数据缺陷。
> 与论文对比声明：论文 Table 3 (F1=0.9702) 是在真实印刷标签上的结果，DAGM 是不同数据集，仅做**跨数据集趋势对照**，非同协议复现。

## 2. 灰度适配

PLDD 原设计为 RGB，DAGM 是灰度图像（R=G=B）。

### 2.1 LDCE 色差模块

灰度图 R=G=B 时，加权欧氏色差 ΔC 退化为灰度差的常数倍。数学上等价但**阈值行为改变**——同一 T_filter 值在灰度和 RGB 下含义不同，必须重新标定。

### 2.2 ICSM 梯度模块

RGB 三通道梯度在灰度图上相同，平均后等于单通道。F(r,m) 和余弦相似度的数学形式不变。

### 2.3 不修改代码，但需重新标定所有参数

| 参数 | 合成数据最优 | DAGM 标定范围 | 依据 |
|------|------------|-------------|------|
| T_filter | 5 | [2, 3, 5, 8, 10, 15, 20, 30] | 灰度 ΔC 量级可能不同 |
| T_score | 0.6 | [0.3, 0.4, 0.5, 0.55, 0.6, 0.65, 0.7, 0.8] | ICSM 分数分布未知 |
| T_r | 0.1 | [0.05, 0.1, 0.2, 0.3, 0.5] | 覆盖低/中/高 |
| T_m | 50 | [10, 30, 50, 80, 100] | 当前仅单点，需扫描 |
| t_bg | 2.0 | [2, 5, 10, 15] | DAGM 有真实纹理 |
| n, l | 4, 5 | 不变 | 论文固定值 |

## 3. 参数策略：先单类标定，后跨类验证

### 3.1 单类标定策略

- **标定集**：Class1（71 张缺陷图，数量适中，纹理典型）
- **方法**：先固定 n=4, l=5，分两步标定
  - Step 1：T_filter × T_score 网格（8×8=64 组合）
  - Step 2：固定最优 T_filter/T_score，扫描 T_r × T_m（5×5=25 组合）
- **选择标准**：F1 最优

### 3.2 跨类验证

用 Class1 标定的最优参数，跑**全部 10 类**，记录各类 F1/P/R。
- 如果某类效果明显差，记录为该类需单独标定
- 最终报告包含 10 类汇总 Mean F1 + 各类明细

## 4. 测试执行（4 Phase）

### Phase 1：Pipeline 通路验证（Class1，默认参数）

- 确认 DAGM 数据加载、GM 配准、LDCE、ICSM 全流程不崩溃
- 记录默认参数基线指标
- 检查 bg_density（DAGM 真实纹理可能 > 30%，M_bg 启用）

### Phase 2：参数标定（Class1）

- Step 1：T_filter × T_score 网格（64 组合）
- Step 2：T_r × T_m 网格（25 组合）
- 输出最优参数组合

### Phase 3：全 10 类验证

- 用 Phase 2 最优参数跑全部 10 类
- 记录各类 F1/P/R + Mean F1
- 与论文 Table 3 做趋势对照

### Phase 4：M_bg 对比（可选）

- 在 Phase 3 基础上，禁用 M_bg 跑 Class1 对比
- DAGM 有真实纹理，M_bg 可能有效

## 5. 评估指标

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| F1 | 全局聚合（总 TP/FP/FN → 2PR/(P+R)） | 主指标 |
| Precision | TP/(TP+FP) | — |
| Recall | TP/(TP+FN) | — |
| 目标级检测率 | 有缺陷图检测到 ≥1 缺陷的比例 | 辅助指标 |
| 速度 | 平均单图耗时 | — |

GT 匹配规则：预测掩码与 GT 掩码逐像素比对，TP=两者都>0 的像素数。

## 7. 风险

| 风险 | 缓解 |
|------|------|
| PLDD 为 RGB 设计，灰度效果可能差 | 核心算法与颜色无关，数学验证通过 |
| DAGM GM 是单张，配准可能不准 | ECC 配准处理小变换；如不准，后续可手动对齐 |
| 参数标定耗时（89 组合 × 575 张） | 每组合约 4-5 分钟，总计约 6-8 小时；可先跑子集 |
| 与论文不可直接对比 | 明确声明为跨数据集趋势对照 |
