# 逐文件优化检查清单

> 基于 docs/绘本制作规范 中的优化方案
> 每个HTML文件逐个检查、优化、测试

---

## 检查项（每个文件必检）

### A. 基础结构
- [ ] 有 `<!DOCTYPE html>` 和完整HTML结构
- [ ] `<meta charset="UTF-8">`
- [ ] `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">`
- [ ] 引用 `shared/courseware.css`
- [ ] 引用 `shared/courseware.js`
- [ ] 引用 `shared/village-reporter.js`
- [ ] 引用 GSAP CDN

### B. 内容类型标记
- [ ] `<html>` 或 `<body>` 有 `data-type` 属性
  - 童谣: `data-type="nursery"`
  - 绘本故事: `data-type="story"`
  - 科普互动: `data-type="science"`
  - 课件教材: `data-type="courseware"`

### C. 视觉风格（按类型）
- [ ] 童谣: Fredoka One字体、橙色系、高饱和
- [ ] 绘本故事: Nunito字体、暖色渐变、对话气泡
- [ ] 科普互动: Nunito字体、蓝绿色系、信息卡片
- [ ] 课件教材: Nunito字体、学科配色（英语绿/语文红/数学蓝）

### D. 响应式
- [ ] 有 `@media (max-width: 500px)` 断点
- [ ] 按钮最小 44×44px（触摸友好）
- [ ] 文字在平板上清晰可读

### E. 交互功能
- [ ] 有翻页导航（前进/后退按钮）
- [ ] 有页面指示器（dots）
- [ ] 有语音朗读按钮（speakPage）
- [ ] 最后一页有庆祝动画（celebrate()）
- [ ] 触摸滑动翻页支持

### F. 内容质量
- [ ] 文字无错别字
- [ ] 中英文对照正确
- [ ] emoji/图标使用恰当
- [ ] 页面数量合理（5-15页）
