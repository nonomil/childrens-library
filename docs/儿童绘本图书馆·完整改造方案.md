# 儿童绘本图书馆·完整改造方案 v1.0

> 目标用户：6岁，我的世界玩家，平板横屏使用
> 目标仓库：nonomil/childrens-library（110个HTML课件，120k行代码）
> 核心问题：内容够（110个课件），但孩子打开是"一堆列表"，没有进入感和持续动力
> 改造原则：**不重构课件内部，用"世界"包裹课件**

---

## 一、问题诊断

### 孩子视角

| 现在 | 期望 |
|------|------|
| 打开是课件列表 | 打开是"我的村庄" |
| 翻完一页是"下一页" | 翻完是"挖到了新方块" |
| 答对题目打个勾 | Steve举起钻石剑庆祝 |
| 没有记忆，每次重新开始 | 上次建的房子还在 |
| 不知道学了多少 | 集市门口多了旗帜 = 学了3课数学 |

### 技术视角

| 问题 | 影响 | 严重度 |
|------|------|--------|
| 无入口页 | 孩子面对110个文件不知道点哪个 | **阻塞体验** |
| CSS/JS大量重复 | 111×300行内联样式，改一处要改111处 | 高（工程债） |
| 无进度系统 | 孩子没有"自己的存档"感 | 高（留存） |
| 共享库太薄 | courseware.js仅133行，大量逻辑重复 | 中 |
| 无分支叙事 | 所有课件线性，没有选择→不同结局 | 中 |

## 二、改造路线（三阶段）

**总原则：每阶段独立可交付，不依赖下一阶段。先解决体验，再优化工程。**

| 阶段 | 名称 | 核心交付 | 周期 | 改动范围 |
|------|------|---------|------|---------|
| **Phase 1** | 村庄地图 | Minecraft风格主页替换列表 | 3-5天 | 新增文件，**不碰课件** |
| **Phase 2** | 成就存档 | 进度系统 + 装饰解锁 + 每日任务 | 4-6天 | 课件加1行script引用 |
| **Phase 3** | 内容优化 | 公共CSS提取 + 音频管理 + 分支故事 | 持续 | 渐进式，不一次性改111个文件 |

### 3.5 Steve角色动画

const steve = {
  x: 200, y: 300, direction: 1, frame: 0, frameTimer: 0,
  FRAME_INTERVAL: 8, SPEED: 1.2,
  spritesheet: 'images/steve-walk.webp',
  patrol: { minX: 100, maxX: 600 }
};

function updateSteve() {
  steve.x += steve.SPEED * steve.direction;
  if (steve.x > steve.patrol.maxX || steve.x < steve.patrol.minX) {
    steve.direction *= -1;
  }
  steve.frameTimer++;
  if (steve.frameTimer >= steve.FRAME_INTERVAL) {
    steve.frame = (steve.frame + 1) % 4;
    steve.frameTimer = 0;
  }
}

### 4.3 课件接入方式（最小改动）

**对现有课件的唯一改动**：在每个HTML的`<head>`里加一行：

```html
<script src="../shared/village-reporter.js"></script>
```

`village-reporter.js` 自动监听页面的 `celebrate()` 调用，完成时上报进度。

批量添加用Python脚本：

```python
import os
COURSEWARE_DIR = 'courseware'
INSERT_LINE = '<script src="../shared/village-reporter.js"></script>\n'
for f in os.listdir(COURSEWARE_DIR):
    if not f.endswith('.html'): continue
    path = os.path.join(COURSEWARE_DIR, f)
    with open(path, 'r', encoding='utf-8') as fh:
        content = fh.read()
    if 'village-reporter' not in content:
        content = content.replace('</head>', INSERT_LINE + '</head>', 1)
        with open(path, 'w', encoding='utf-8') as fh:
            fh.write(content)
```

### 5.2 音频管理统一（P1）

扩展 `courseware.js`，增加音频队列：

```javascript
window.audioQueue = {
  current: null,
  play(src, text, onEnd) {
    this.stop();
    var a = new Audio(src);
    a.onerror = function() { speakTTS(text); if(onEnd) onEnd(); };
    a.onended = function() { if(onEnd) onEnd(); };
    a.play().catch(function(){ speakTTS(text); if(onEnd) onEnd(); });
    this.current = a;
  },
  stop() {
    if (this.current) { this.current.pause(); this.current = null; }
    if (window.speechSynthesis) window.speechSynthesis.cancel();
  },
  playSequence(items) {
    var i = 0, self = this;
    function next() {
      if (i >= items.length) return;
      self.play(items[i].src, items[i].text, function() { i++; next(); });
    }
    next();
  }
};
```
