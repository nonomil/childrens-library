### 解锁逻辑代码分析

```javascript
// village.js:196-205 当前实现
window.isZoneUnlocked = function(zone, state) {
  var req = ZONE_CONFIG[zone].unlockRequirement;
  if (req === 0) return true;
  var totalOther = 0;
  Object.keys(state.zones).forEach(function(k) {
    if (k !== zone) totalOther += state.zones[k].totalCompleted;
  });
  return totalOther >= req;
};
```

**问题**：数学集市 `unlockRequirement: 3`，但检查的是所有其他zone总完成数。如果孩子完成了3节中文课，数学集市也会解锁，这不符合规范"完成3课英语"的要求。

**修复方案**：添加 `requiredZone` 字段，支持检查特定zone完成数。

### 规范要求的金币公式（来自 R2）

```javascript
// Habitica 公式
baseGold = 1.0 + (task.value * 0.1)
goldEarned = baseGold * DIFFICULTY_FACTORS[task.priority]
// priority: 0.1(简单) / 1.0(普通) / 1.5(难) / 2.0(困难)

// 升级公式
expToLevel(n) = Math.floor(n * 2 * (Math.pow(n, 0.9) / 4.0) + 10)
```

### 当前实现

```javascript
// village-reporter.js:72-98
coinsEarned += 5;           // 完成课程 +5
if (stars >= 3) coinsEarned += 3;  // 三星额外 +3
dailyBonus = 10;            // 每日任务 +10
streakBonus = Math.min(state.streakDays, 10) * 2;  // 连续+2/天，上限+20
```

**评估**：固定值比 Habitica 公式更适合6岁儿童（简单可预期），但缺少经验值/等级系统的长期激励。建议保留固定金币值，但添加简化版等级系统。

### 规范要求的完整CSS变量方案（来自 R4）

```css
/* 童谣/儿歌：明快高饱和，剪纸/水彩感 */
[data-type="nursery"] {
  --bg: #FFF9E6;
  --accent: #FF6B35;
  --text: #5D4037;
  --card-bg: #FFFFFF;
  --card-radius: 24px;
  --font-display: '站酷快乐体', 'Comic Neue', cursive;
}

/* 绘本故事：暖色渐变，柔和 */
[data-type="story"] {
  --bg: #FFF8F0;
  --accent: #FF8C42;
  --text: #333333;
  --card-radius: 20px;
}

/* 科普互动：清爽蓝绿，信息分区 */
[data-type="science"] {
  --bg: #F0F8FF;
  --accent: #2196F3;
  --text: #333;
}

/* 课件教材：纯白，清晰结构化 */
[data-type="courseware"] {
  --bg: #FAFAFA;
  --accent: #4CAF50;
  --text: #333;
}
```

**结论**：128个课件均未使用规范要求的 CSS 变量主题系统。每种类型各自硬编码颜色。

**实现注意**：128个文件已有内联 `<style>` 标签，`[data-type]` 选择器的特异性可能低于内联样式。解决方案：用 `:root[data-type]` 或 `html[data-type]` 提升特异性，必要时对关键变量用 `!important`。优先在 `shared/courseware.css` 中定义变量，课件内部用 `var(--bg)` 引用。
