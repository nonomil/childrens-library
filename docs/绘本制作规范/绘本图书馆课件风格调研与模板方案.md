# 绘本图书馆课件风格调研与模板方案

## 一、概述

本报告整理了在为非名义绘本图书馆（nonomil\.github\.io/childrens\-library）设计课件的全过程中，进行的调研、参考项目、风格实验和课程体系对标分析，最终提出可复用的课件模板架构。

调研范围覆盖：开源交互绘本项目、儿童教育视觉风格、课程内容体系对标、HTML课件技术选型。

## 二、参考开源项目

### 1\. The Real Mermaids — 纯 HTML 单文件绘本

- **类型**: 纯前端单文件交互式故事绘本

- **特点**: 零外部依赖、纯 CSS 动画、响应式布局、一页滚动式叙事

- **参考价值**: 展示了单文件 HTML 能做到的叙事品质，无需任何框架

- 参考：类似 Github 上各类纯 HTML 绘本项目

### 2\. buildfastwithai/storybook — AI 绘本生成器

- **类型**: AI 驱动的故事绘本生成工具

- **特点**: 用户输入提示词 → AI 生成完整故事 \+ 配图描述 → 输出可交互绘本

- **参考价值**: 从\&\#34;内容生成到交付\&\#34;的完整流水线思路

- 链接: https://github\.com/buildfastwithai/storybook

### 3\. Markdown\-Flipbook — Markdown 转翻页书

- **类型**: Markdown 格式内容 → 3D 翻页书展示

- **特点**: 内容与呈现分离，写 Markdown 即可生成翻页书

- **参考价值**: 内容创作流程简化思路——写 md → 出翻页书，降低内容生产成本

- 链接: https://github\.com/ \(搜索 Markdown\-Flipbook\)

### 4\. Turn\.js — 3D 翻页效果库

- **类型**: JavaScript 翻页/翻书效果库

- **版本**: v3（cdnjs 最新），非 v4

- **特点**: 模拟真实翻书交互、支持触摸滑动、键盘翻页

- **教训**: 必须 self\-host（CDN 版本易踩坑），固定尺寸\(800×600\)需要响应式适配

- **适用场景**: 以阅读为主的故事类课件（如齿轮绘本原版）

### 5\. GSAP — Web 动画引擎

- **类型**: 高性能 JavaScript 动画库

- **使用**: 现有 `gears\-transmission\.html` 页面用 GSAP 做齿轮旋转、机器人动画

- **特征**: Timeline 控制、缓动效果丰富、兼容性好

- **局限**: 外部 CDN 依赖，离线时不可用

## 三、小红书参考案例：DeepSeek 齿轮互动

### 来源

小红书笔记：「用DeepSeek给娃做个齿轮连动，他居然秒懂！」

链接: https://www\.xiaohongshu\.com/explore/ \[搜索标题可找到\]

### 核心特点（对比分析）

这个案例是导致我们**推翻翻页书方案**的关键触发点：

- ❌ 翻页书（Turn\.js）方案：有页面边界 → 内容易被裁剪 → 手机端体验差

- ✅ 互动实验室方案（Canvas）：一个页面解决所有问题

该作品使用 DeepSeek V4 生成，核心功能：

- 拖拽太阳齿轮 → 小齿轮反向啮合旋转

- 小齿轮上的黑色标记追踪旋转半圈

- 齿数滑块调节（7\-20齿）→ 实时计算齿轮比

- 方向切换按钮

- 齿轮眨眼、冒星星特效

- **无翻页、无裁剪、全屏Canvas**

### 关键认知转变

**对于以「动手实验」为目的的儿童课件→ 翻页书是错误的容器。**

- 交互模拟器、物理实验 → 全屏 Canvas 单页

- 故事阅读、语言学习 → 翻页书或滚动叙事

- 混合内容（故事\+互动） → 叙事段落后嵌 Canvas 交互区

## 四、视觉风格研究

### 4\.1 配色体系

基于现有课件风格（`gears\-picturebook\.html` 系列）和 IMAGE\_PROMPT\_GUIDE\.md：

- **背景**: \#FFF8F0 奶油色 → \#FFF0E0 暖渐变

- **主色**: \#FF6B35 活力橙 → \#FF8C42

- **辅色**: \#2196F3 湖蓝 → \#64B5F6

- **卡片**: 白色底 \+ border\-radius: 20px \+ 柔和阴影

- **字体**: 系统字体栈（\-apple\-system, BlinkMacSystemFont, sans\-serif）

- **圆角**: 所有元素圆角处理，营造\&\#34;柔软安全\&\#34;的儿童感

### 4\.2 三个视觉变体实验（齿轮绘本）

通过 OpenCode \+ MiMo V2\.5 生成了 3 个视觉变体，探索不同风格：

|版本|风格|文件大小|特点|
|---|---|---|---|
|绘本版|原版暖色|48KB|暖色调渐变、圆角装饰、大图标|
|梦幻版|海洋渐变|49KB|\#0F2027 → \#203A43 → \#2C5364 深蓝渐变、彩光特效|
|水彩版|水彩暖橙|44KB|水彩质感背景、柔和暖橙配色、手绘装饰线|
|琥珀版|琥珀极简|42KB|琥珀色 \#FFBF00 为主、极简布局、大留白|

### 4\.3 课程体系对标研究

#### 语文

- **小羊上山 L1**: 60字零起点，每课约5\-8字

- **部编版一年级上册**: 280识字/100会写，第1单元约40字

- **编排规律**: 象形字（日月水火）→ 笔画 → 复合字 → 短句 → 古诗

- **对标设计**: 24课 × 8\-12字/课 ≈ 96字，对标小羊上山 L1 \+ 部编版扩展

#### 英语

- **Dolch Sight Words Pre\-Primer**: 40词核心视觉词

- **牛津树/培生幼儿**: 叙事驱动 \+ 重复句式

- **美幼教材 Welcome to Our World**: 主题单元制

- **对标设计**: 每课嵌入3\-5个Dolch词，24课覆盖Pre\-Primer 40词 \+ 20主题词

#### 数学

- **幼儿园数学大纲**: 数数→比较→加减→形状→测量

- **对标设计**: 24课螺旋晋升，每课基础\+拓展双文件

## 五、现有课件格式分析

### 5\.1 当前结构（Markdown → 图片 → HTML）

以英语第 1 课为例（`lesson\-01\-hello\.md`，221行）：

- **叙事层**: Minecraft Steve 为主角，在方块村冒险

- **结构**: 9页 = 故事\(4页\) \+ 词典\(1页\) \+ 练习\(1页\) \+ 歌曲\(1页\) \+ 挑战\(1页\) \+ 庆祝\(1页\)

- **内容要素**: 对话气泡、配图、双语对照、练习、Common Mistakes、Think About It、Cross\-Curricular Links

- **角色**: Steve（孩子替身）、Alex（玩伴）、Bob（村民向导）

### 5\.2 风格优势

- 角色一致性（Steve/Alex/Bob 贯穿全课程）

- 每课完整闭环（学习→练习→挑战→庆祝）

- 双语对照设计

- Common Mistakes \+ Think About It 体现深度

### 5\.3 可改进点

- 配图缺口大（\~239张语文、大量数学、英语还有缺口）

- 交互性弱（纯静态 Markdown，缺少互动元素）

- 各科格式不统一（数学HTML、中英Markdown）

## 六、模板架构方案 TEMPLATE\_CONFIG

### 核心思路

**一个 CONFIG 对象控制全部内容，改 topic 就能换课题。**

```JavaScript
// ① 改这里就能换主题
const TEMPLATE_CONFIG = {
  topic: {
    title: "咕噜咕噜传动王国",
    emoji: "⚙️",
    sections: [ /* 所有页面/章节定义 */ ]
  }
}

// ② 这部分引擎层永远不改
// Canvas渲染器、游戏引擎、测验引擎、滚动动画...
```

### 组件类型

|组件ID|用途|可复用性|
|---|---|---|
|interactive\-gear|单齿轮交互（拖拽旋转\+齿数调节）|任何旋转/交互类|
|dual\-gear|双齿轮啮合\+齿比显示|比例/配对/对比类|
|chain\-drive|链条传动\+张力控制|带的传动、传输类|
|linkage|连杆机构（转圈→摆动）|任何机构可视化|
|belt\-drive|传动带\+交叉/平行切换|传输类|
|gear\-lab|增强物理实验室|通用交互实验室|
|game\-match|配对游戏（滑块匹配）|任何配对类（数字匹配、单词匹配）|
|game\-repair|修理游戏（拖部件）|任何拼装/修理类|
|game\-sort|分类游戏（拖入桶）|分类归纳类（动物分类、形状分类）|
|game\-chain|排序游戏|任何序列排列|
|game\-puzzle|拼图补全|填空/补全类|
|game\-build|搭建创造|自由搭建类|
|quiz|知识测验|通用测验|

### 换主题示例

把齿轮主题换成太阳系，只需改 CONFIG：

```JavaScript
TEMPLATE_CONFIG.topic = {
  title: "🌍 太阳系大冒险",
  emoji: "🌍",
  sections: [
    { id: "sun", icon: "☀️", title: "太阳", component: "interactive-gear",
      componentConfig: { prompt: "太阳是太阳系的中心..." } },
    { id: "orbit", icon: "🔄", title: "行星轨道", component: "dual-gear",
      componentConfig: { prompt: "行星绕太阳公转..." } },
    // ... 其他页面复用相同组件引擎
  ]
}
```

## 七、总结与建议

### 推荐的课件类型

1. **故事型课件**（适合语文/英语学习）

    - 主角叙事 \+ 翻页/滚动 \+ 配图 \+ 练习

    - Turn\.js 或 Markdown\-Flipbook 方案

    - 重点：角色一致性、重复句式、配图质量

2. **互动型课件**（适合科学/数学实验）

    - Canvas 渲染 \+ 全屏无边界 \+ 拖拽交互 \+ 实时反馈

    - 重点：互动深度、物理正确的模拟、反馈趣味性

3. **混合型课件**（通用模板方案）

    - 顶部故事叙事 \+ 中段互动实验室 \+ 底部小游戏/测验

    - TEMPLATE\_CONFIG 架构驱动

    - 重点：数据与呈现分离，一次模板多次使用
